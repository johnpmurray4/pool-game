# tools/

Development tooling that never ships:

- **Debug visualizer** (planned): desktop app that renders `core` simulations
  top-down with ball paths, event markers, and slow-motion playback — the main
  instrument for physics tuning against real UK pool footage.
- **Tuning harness** (planned): batch-runs canned shots across parameter sweeps
  of `PhysicsConfig` and reports trajectory differences.
